# 🧩 WordFlow English

WordFlow Englishは、**Gemini API**を活用した新しい学習体験を提供する、パズル感覚の英作文Webアプリケーションです。  
ユーザーは言いたいこと（日本語）をゴールに設定し、提示される英単語を選択しながら、自然な英語の語順感覚を身につけることができます。

![WordFlow English Screenshot](https://via.placeholder.com/800x400.png?text=WordFlow+English+App)

## ✨ 主な機能
* **三段構成のUI:** 「言いたいこと」「パズル構築」「現在の日本語訳」の3つの視覚的レイヤーで学習者の認知負荷を下げます。
* **リアルタイム・フィードバック:** 単語を1つ選ぶ（または手動入力する）たびに、Gemini APIが即座に「今の途中までの英文」を日本語に翻訳して表示します。
* **Undo ＆ 手動入力機能:** 「1つ戻る」機能で試行錯誤をサポート。選択肢にない単語もフォームから自由に追加できます。
* **超高速＆超軽量:** 重いAIモデルをローカルで動かす必要がなく、PCスペックに依存しない爆速レスポンスを実現しました。

## 🧠 本プロジェクトにおけるアーキテクチャの工夫（設計思想）

本アプリは、単にAPIを叩くだけではなく、ユーザー体験（UX）とシステムの堅牢性を両立するための設計を取り入れています。

### 1. タスクの分離による「ハルシネーション」の抑制と高速化
LLMに「正解の推論」「ダミー単語の生成」「途中経過の翻訳」を1回のプロンプトで同時に要求すると、処理が遅くなり、出力フォーマットが崩れる原因になります。  
**👉 【解決策】**  
処理の責務を完全に分離しました。
1. **正解文の生成**: 最初に1回だけAPIに「ゴール（英文全体）」を生成させ、状態として保持。
2. **ダミー生成の非LLM化**: 正解単語をキーにして、静的なルックアップテーブル（`distractor_manager.py`）から即座にダミー4語を取得。APIへの無駄なリクエストを減らし、確実性と速度を劇的に向上させています。
3. **リアルタイム翻訳**: 1語追加されるたびに専用プロンプトでAPIを呼び出し、高精度な翻訳を瞬時に返します。

### 2. 環境変数と `secrets.toml` を用いたセキュアな設計
APIキーや利用するモデル名（`gemini-2.0-flash`等）をコード内に直接記述（ハードコード）すると、セキュリティリスクやメンテナンス性の低下を招きます。  
**👉 【解決策】**  
Streamlit標準の `st.secrets` およびシステムの環境変数（`os.environ`）から安全に設定を読み込むフォールバック設計を採用。将来モデルがアップデートされても、設定ファイルを1行書き換えるだけで対応可能なメンテナンスフリーな構造にしています。

### 3. 分析・運用を視野に入れたロギングシステム
AIの推論結果がブラックボックスにならないよう、専用のロガーを実装しています。  
**👉 【解決策】**  
通信エラー等は `error.log` に記録し、アプリをクラッシュさせずにユーザーに優しいエラーメッセージを返すフェイルセーフを実装。また、ユーザーの入力とAIの出力を `analytics.jsonl` に構造化データとして記録し、将来のプロンプト改善に活かせるようにしています。

## 📁 ディレクトリ構造

UIとロジックを完全に分離したモダンなコンポーネント指向を採用しています。

```text
wordflow-english/
├── pyproject.toml         # パッケージ・依存関係管理 (uv)
├── README.md              # 本ドキュメント
├── .streamlit/
│   └── secrets.toml       # 🔐 APIキー等を管理する設定ファイル (Git管理外)
├── logs/                  
│   ├── error.log          # [自動生成] エラーログ
│   └── analytics.jsonl    # [自動生成] AIの推論・翻訳の分析用JSONログ
├── src/
│   ├── state_manager.py   # セッション状態(Session State)の管理
│   ├── llm_engine.py      # Gemini APIクライアントの初期化・プロンプト処理
│   ├── distractor_manager.py # ダミー単語のルックアップテーブル
│   └── components/        # UIパーツ
│       ├── goal_ui.py     # 目標入力・表示エリア
│       ├── puzzle_ui.py   # パズル・ゴーストテキスト・手動入力エリア
│       └── trans_ui.py    # リアルタイム翻訳エリア
└── app.py                 # 画面のルーティングを統括するメインファイル
```

## 🛠️ 環境構築と実行

本プロジェクトは高速なパッケージマネージャである `uv` を使用しています。

### 1. 依存関係のインストール
プロジェクトのルートディレクトリで以下のコマンドを実行します。
```bash
uv sync
```

### 2. APIキーの設定
プロジェクトのルートディレクトリに `.streamlit` フォルダを作成し、その中に `secrets.toml` ファイルを作成します。以下の内容を記述してご自身のGemini APIキーを設定してください。

**`.streamlit/secrets.toml`**
```toml
GEMINI_API_KEY = "あなたのAPIキーをここに記述"
GEMINI_MODEL_NAME = "gemini-2.0-flash"
```

### 3. アプリケーションの起動
以下のコマンドを実行すると、ローカルサーバーが立ち上がりブラウザでアプリが開きます。
```bash
uv run streamlit run app.py
```

## 📝 使い方
1. 画面上部のテキストボックスに、英語にしたい内容を日本語で入力し、「パズルを作成」をクリックします。
2. 提案される5つの英単語ボタンから正しいと思うものをクリックして、文を組み立てていきます。
3. 選択肢にない単語は、テキストボックスから手動で入力して追加できます。
4. 途中で迷った時は、「💡 ヒントを見る」をクリックするか、画面下の「現在の日本語訳」を参考にしてください。
5. 「⏪ 1つ戻る」で何度でもやり直せます。文が完成したら「🏁 完成」ボタンを押してください。
